# チーム同期(任意機能)の設置手順 — Google Apps Script テンプレート

ポスティングマップの「☁️ チーム同期」を使うと、メンバー全員がその場で登録した
区域・ルートを**チーム共有のスプレッドシート経由で同期**できます(ファイルの受け渡し不要)。

## 大事な前提(必ずお読みください)

- この仕組みは**利用チーム自身のGoogleアカウントに設置**します。データは**あなたのチームのスプレッドシートにのみ**保存され、**ツール作成者には一切送信されません**(作成者はサーバを運営せず、データを預かりません)。
- **URLとトークンを知っている人は誰でも読み書きできます**。共有範囲の管理はチームの責任で行ってください。トークンは推測されにくい長いランダム文字列にし、メンバー以外に渡さないでください。
- 「どこを回ったか」という活動データをクラウド(チームのGoogleアカウント)に置くことになります。その是非はチームで判断してください。ファイル受け渡し方式(GeoJSON書出→読込の統合)でも十分運用できます。
- 設置・運用・トラブル対応はチームで行ってください(作成者はサポート・責任を負いません。詳細はリポジトリの LICENSE / 免責表示参照)。

## 設置手順(約10分・無料)

1. **スプレッドシートを新規作成**(チームの共有ドライブ推奨)。名前は自由(例: ポスティング同期)
2. メニュー **拡張機能 → Apps Script** を開く
3. エディタの内容を全て消し、同じフォルダの **`Code.gs` の中身を貼り付ける**
4. 冒頭の `TOKEN = "CHANGE_ME_TO_LONG_RANDOM_STRING"` を**長いランダム文字列に変更**(例: パスワード生成ツールで32文字)
5. **デプロイ → 新しいデプロイ → 種類: ウェブアプリ**
   - 説明: 任意
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 「デプロイ」→ 表示された **ウェブアプリURL(https://script.google.com/macros/s/…/exec)** を控える
7. ポスティングマップの **「☁️ チーム同期」** ボタン → URLとトークンを入力
8. 以後「☁️ チーム同期」を押すたびに **送信(自分の変更)→受信(全員の変更)** が実行されます

メンバー全員が同じURL・トークンを設定すれば共有完了です。

## 仕様・制限

- 同期は**ボタンを押した時だけ**実行(自動常時同期ではありません)。作業の前後に押す運用を推奨
- 競合時は**更新時刻の新しい方**を採用
- 削除も同期されます(削除の記録=トゥームストーン方式)。完全に消したい場合はスプレッドシートの `sync` シートから該当行を削除
- Google Apps Script の無料枠(1日あたりの実行回数・実行時間)内で動作します。数人〜十数人規模の通常利用なら十分です
- 設定の変更・解除は「☁️ 同期」ボタンを **Shift+クリック(PC)または長押し(スマホ)** → 設定画面(URL入力欄を空にすると解除)

## トークンを変更したいとき(漏洩時など)

1. Apps Script の `TOKEN` を新しい値に変更 → **デプロイ → デプロイを管理 → 編集(鉛筆) → バージョン: 新バージョン → デプロイ**
2. メンバー全員がマップ側の設定を新トークンに更新
