# チーム同期(任意機能)の設置手順 — Google Apps Script テンプレート

ポスティングマップの「☁️ チーム同期」を使うと、メンバー全員がその場で登録した
区域・ルートを**チーム共有のスプレッドシート経由で同期**できます(ファイルの受け渡し不要)。

## ⚠️ すでに設置済みのチームへ(2026-10-06 更新・再デプロイのお願い)

`Code.gs` を次の4点で更新しました。**代表者は `Code.gs` を貼り直し、
[デプロイ]→[デプロイを管理]→[編集(鉛筆)]→[バージョン: 新バージョン]→[デプロイ] を実行してください。**
貼り直さないと、以下はお使いのチームには反映されません(古いままでも動作はします)。

1. 合言葉(TOKEN)を既定値から変えていない場合は応答しないようにしました(設置ミスの検知)
2. 送信の応答に全状態を含めるようにし、**合言葉をURLに載せずに済む**ようにしました
3. 点数の非常に多いルート(おおむね2,000点以上)は、保存先の1セル上限を超えるため**そのルートだけ**スキップします(同期全体が失敗しなくなります)
4. 端末の時計が進んでいる場合に、その方の変更だけが常に勝ってしまう問題を直しました

**メンバー側の操作は変わりません**(URLと合言葉はそのまま使えます)。
`Code.gs` を貼り直すとき、**`TOKEN` の行だけは今お使いの値に書き戻してください**
(テンプレートの既定値に戻すと同期が止まります)。
⚠️ **いまお使いの合言葉が20文字未満の場合は、20文字以上の新しい値に変えて、メンバー全員に配り直してください。**
新しい `Code.gs` は短すぎる合言葉を設置ミスとみなして応答しません(短い合言葉は推測されるため)。

## 大事な前提(必ずお読みください)

- この仕組みは**利用チーム自身のGoogleアカウントに設置**します。データは**あなたのチームのスプレッドシートにのみ**保存され、**ツール作成者には一切送信されません**(作成者はサーバを運営せず、データを預かりません)。
- **URLとトークンを知っている人は誰でも読み書きできます**。共有範囲の管理はチームの責任で行ってください。トークンは推測されにくい長いランダム文字列にし、メンバー以外に渡さないでください。
- 「どこを回ったか」という活動データをクラウド(チームのGoogleアカウント)に置くことになります。その是非はチームで判断してください。ファイル受け渡し方式(GeoJSON書出→読込の統合)でも十分運用できます。
- 設置・運用・トラブル対応はチームで行ってください(作成者はサポート・責任を負いません。詳細はリポジトリの LICENSE / 免責表示参照)。

## まずはここだけ — メンバーのやること(設置は不要・1分)

“倉庫”の設置は**チームの代表者1人だけ**がやります。メンバーは以下の3ステップだけです。

1. 代表者から **URL**(`https://script.google.com/…` で始まる長いアドレス)と**合言葉(トークン)**を受け取る
2. ポスティングマップの **「☁️ 同期」** を押す → 説明のあと ①URL ②合言葉 を貼り付ける(入力は最初の1回だけ)
3. 以後は**作業の前後に「☁️ 同期」を押すだけ**。自分の変更が送られ、全員の変更が届きます

- 何度押しても大丈夫です(**同じ図形は自動で1つに整理**され、増えません)
- URLや合言葉を入れ直したいときは「☁️ 同期」を **Shift+クリック(PC)または長押し(スマホ)**

## 設置手順(約10分・無料)

1. **スプレッドシートを新規作成**(チームの共有ドライブ推奨)。名前は自由(例: ポスティング同期)
2. メニュー **拡張機能 → Apps Script** を開く
3. エディタの内容を全て消し、同じフォルダの **`Code.gs` の中身を貼り付ける**
4. 冒頭の `TOKEN = "CHANGE_ME_TO_LONG_RANDOM_STRING"` を**長いランダム文字列に変更**(例: パスワード生成ツールで32文字)
   - **変更しないと同期は動きません。** 既定値のまま／20文字未満のときは、安全のため応答しない作りになっています(既定値はこの公開リポジトリに書いてあるため、変え忘れるとURLを知った人が誰でもチームの全データを読み書き・削除できてしまいます)
5. **デプロイ → 新しいデプロイ → 種類: ウェブアプリ**
   - 説明: 任意
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 「デプロイ」→ 表示された **ウェブアプリURL(https://script.google.com/macros/s/…/exec)** を控える
7. ポスティングマップの **「☁️ チーム同期」** ボタン → URLとトークンを入力
8. 以後「☁️ チーム同期」を押すたびに **送信(自分の変更)→受信(全員の変更)** が実行されます

メンバー全員が同じURL・トークンを設定すれば共有完了です。

## 仕様・制限

- 同期は**ボタンを押した時だけ**実行(自動常時同期ではありません)。作業の前後に押す運用を推奨
- 競合時は**更新時刻の新しい方**を採用します。この「更新時刻」は**操作した方の端末の時計**です。**メンバー全員の端末で、日付と時刻を「自動設定」にしてください。** 時計がずれている端末があると、その方の変更だけが常に勝つ／その方の変更が反映されない、という形で**記録が静かに失われます**(エラーは出ません)。端末の時計が5分以上ずれているときは、同期の完了メッセージで警告します
- **誰が消したかは記録されません。** 登録者名はメンバーの端末側で付ける自己申告の値で、照合はしていません。重要な区域の削除は管理者に限り、**週1回は「💾 GeoJSON書出」で日付つきバックアップ**を取ってください
- **点数の非常に多いルート(おおむね2,000点以上のGPX)は同期できません**(保存先スプレッドシートの1セル上限50,000文字のため)。そのルートだけが同期されず、ほかは通常どおり同期されます。ファイル(「💾 GeoJSON書出」→「📂 読込」)で渡してください
- 削除も同期されます(削除の記録=トゥームストーン方式)。完全に消したい場合はスプレッドシートの `sync` シートから該当行を削除
- **選挙が終わったら、スプレッドシートとウェブアプリのデプロイを削除**してください(活動データと氏名を残さないため)
- Google Apps Script の無料枠(1日あたりの実行回数・実行時間)内で動作します。数人〜十数人規模の通常利用なら十分です
- 設定の変更・解除は「☁️ 同期」ボタンを **Shift+クリック(PC)または長押し(スマホ)** → 設定画面(URL入力欄を空にすると解除)

## よくあるつまずき

- **図形が何重にも重なって濃く/真っ青に見える**: 旧版で複数の端末から同期した場合に、同じ図形が重複して増えることがありました(2026-09-15修正済み)。**最新版のマップで「☁️ 同期」を1回押すと、重複が自動で1つに整理されます**(整理した件数が完了メッセージに表示されます)。他のメンバーも次に同期したとき自動で整理されます。ブックマークではなく原本(https://yukinobu-nakamura.github.io/senkyo-maps/)か、最新の配布ファイルを使ってください
- **「トークンが一致しません」**: 合言葉の前後に余分なスペースが入っていないか確認。代表者がトークンを変更した場合は新しい合言葉を入れ直す(Shift+クリック/長押し)
- **同期を押しても何も起きない/失敗する**: インターネット接続と、URLが `https://script.google.com/macros/s/…/exec` の形かを確認。URLは必ずこの形です。**これ以外のあて先を入れてはいけません**(区域・ルートの座標と担当者名・メモ・登録者名が、そのあて先へ送信されます)
- **「Googleのログイン画面が返ってきました」と出る**: デプロイの設定が原因です。[デプロイを管理]→[編集]で **アクセスできるユーザー: 全員** / **次のユーザーとして実行: 自分** になっているかを確認し、**バージョン: 新バージョン**で再デプロイしてください。この失敗では**手元のデータは消えません**(送信できなかっただけです)
- **「設置が未完了です(TOKENを変更してください)」と出る**: 設置手順4をまだ行っていません。`TOKEN` を20文字以上のランダム文字列に変えて、**新バージョンで再デプロイ**してください

## トークンを変更したいとき(漏洩時など)

1. Apps Script の `TOKEN` を新しい値に変更 → **デプロイ → デプロイを管理 → 編集(鉛筆) → バージョン: 新バージョン → デプロイ**
2. メンバー全員がマップ側の設定を新トークンに更新
